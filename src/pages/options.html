Quiet hours

Block all browsing during the hours you set, for example at night so the computer is not used when it is time to sleep.

When on, every website is blocked during the quiet hours below. When off, nothing below is applied.

Uses this computer's local time. All websites are blocked during quiet hours, including Allowed Sites and educational sites. "From" is the first blocked minute and "until" is the first minute browsing is available again (until 08:00 means 07:59 is still blocked). If "until" is earlier than "from", quiet hours run overnight (22:00 → 08:00). If both are the same, there are no quiet hours. A page that is already open is blocked the next time it loads or changes address. Browser pages (chrome://) and these settings stay available. A Telegram message is sent once per quiet period when "Quiet hours attempts" is selected on the Notifications tab.

AI Classification

Classifies the pages your child opens (by address and title only) and blocks them according to the Content Restrictions on the Restrictions tab.

Decision model (fast verdict)

Gives a fast verdict (educational? age-appropriate? which category and risk level?) so a page can be blocked quickly. The extension then decides block or allow from your Content Restrictions lists. Uses OpenRouter Decisions models and an OpenRouter key.

When off, the extension uses the single-call mode with the explanation model below. Needs a key and a pinned model.

Stored locally in this browser as plain text, like the other tokens, and included in the settings export. Get a key at https://openrouter.ai/keys.

Pick a versioned (pinned) build such as liquid/d1.1-20261027. Aliases like ~vendor/model-latest or ids ending in -latest are not accepted, because their behaviour can change without notice. Uses the audience set below. Recommended: typesafe/jev-1.14-20261014. Models marked ✓ were checked with this extension. Other models may reject the request; press "Test model" before saving.

Explanation model (reason + educational suggestion)

Writes the human-readable reason and suggests an educational page. Runs only for pages the decision model blocked, after the page is already blocked. In single-call mode this model also classifies every page.

When off, blocked pages show a short automatic reason (for example: Category "Games" is blocked in the settings.) and no suggestion.

Manage lists and the classification cache from Telegram. Commands apply only to this Chrome profile. In groups, mention the bot (e.g. /allow@YourBotName).

  • Remove: /remove_allow, /remove_restrict, /remove_ignore plus pattern
  • Clear list: /clear_allow confirm (same for restrict / ignore)
  • Cache: /cache_info, /clear_cache confirm
  • Help: /help
